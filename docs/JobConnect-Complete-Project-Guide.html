1. What is this project? (Simple explanation)

Imagine a small version of LinkedIn Jobs / Naukri / Indeed. Three types of people use the website:

  1. Candidate — looks for jobs, uploads resume, applies, tracks status
  2. Employer — posts jobs, reviews applicants, updates application status
  3. Admin — controls the whole system (users, job approvals, categories, stats)

This is not a React app with separate API servers. It is a classic PHP website: when you open a page, PHP talks to MySQL on the server, builds the HTML, and sends the finished page to your browser. That is why the Network tab often shows no XHR/fetch “API” calls — the data is already inside the HTML.

3. How the Backend works

Backend = PHP code that runs on the server before HTML is shown.

FileJob
includes/config.phpDatabase host, name, user, password, upload limits
includes/db.phpCreates PDO MySQL connection
includes/functions.phpLogin checks, flash messages, file upload helpers, CSRF
includes/init.phpStarts session + loads helpers on every page

Request flow (example: Apply to a job)

  1. Candidate opens job-details.php?id=1
  2. PHP loads job from MySQL and shows the page
  3. Candidate clicks Apply → form POSTs to same page
  4. PHP checks login role, CSRF token, resume exists
  5. PHP inserts a row into applications table
  6. User is redirected to Applications list with a success message

Security built in

  • Passwords hashed with password_hash()
  • SQL via PDO prepared statements (helps stop SQL injection)
  • Session login + role checks (candidate/employer/admin)
  • CSRF tokens on important forms
  • Upload validation (PDF resume, image photo/logo, size limits)

7. How to install & run (for a new person)

Option A — XAMPP (most common for college projects)

  1. Install XAMPP and start Apache + MySQL
  2. Copy/clone project into C:\xampp\htdocs\Job-Connect
  3. Open phpMyAdmin → Import → select database.sql → Go
  4. Open browser: http://localhost/Job-Connect/
git clone <your-repo-url>
# then move/copy into htdocs if needed

DB settings (usually already correct) in includes/config.php:

DB_HOST = localhost
DB_NAME = job_recruitment
DB_USER = root
DB_PASS = (empty on default XAMPP)
Important: In this project there is no separate “npm start frontend” and “npm start backend”. Apache runs PHP pages. Frontend CSS/JS are just static files served with those pages.

Option B — Docker (if you already have Docker Desktop)

From the project folder:

docker compose up -d

Then open:

http://localhost:8080/

Useful Docker commands:

# See running containers
docker compose ps

# View web logs
docker compose logs -f web

# Stop everything
docker compose down

# Stop and delete database volume (full reset)
docker compose down -v
docker compose up -d

Docker MySQL (from your PC): host 127.0.0.1, port 3307, user root, password root, database job_recruitment.

8. How to check `database.sql` and the data

A) Read the SQL file in the project

Open database.sql in VS Code / Cursor. You will see:

  • CREATE DATABASE / CREATE TABLE statements
  • INSERT INTO sample users, jobs, applications

B) Check data in phpMyAdmin (XAMPP)

  1. Go to http://localhost/phpmyadmin
  2. Click database job_recruitment
  3. Open tables: users, jobs, applications, …
  4. Click Browse to see rows

C) Check data with Docker MySQL commands

docker exec -it jobconnect-db mysql -uroot -proot job_recruitment

# Inside MySQL:
SHOW TABLES;
SELECT id, email, role, status FROM users;
SELECT id, title, location, status FROM jobs;
SELECT id, job_id, candidate_id, status FROM applications;
EXIT;

One-line examples without entering MySQL shell:

docker exec jobconnect-db mysql -uroot -proot job_recruitment -e "SHOW TABLES;"
docker exec jobconnect-db mysql -uroot -proot job_recruitment -e "SELECT id,title,location,status FROM jobs;"
docker exec jobconnect-db mysql -uroot -proot job_recruitment -e "SELECT id,email,role FROM users;"
